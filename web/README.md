# Frontend (React + Vite + TypeScript)

Aplicación web de trawl-design-lab: casos de diseño, editor de paneles, resultados, gráficos,
planos SVG, comparación y descarga de informes. Interfaz en español.

```bash
npm ci
npm run dev        # requiere la API: uv run trawlkit serve --port 8000
```

Documentación completa (variables de entorno, arquitectura, pruebas): [`docs/web.md`](../docs/web.md).
