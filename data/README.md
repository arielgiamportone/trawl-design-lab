# Datos

- `fao_a3_standard.yaml`, `fao_a3_modified.yaml`: especificación por paneles de la red FAO A-3 (Fase 1).
- `vessels.yaml`, `doors.yaml`, `floats.yaml`, `ropes.yaml`, `warps.yaml`: catálogos (Fase 1).
- `reference/`: tablas de referencia (proporciones Nomura, razones de corte, factor K de nudos,
  catenaria, profundidad→cable filado) extraídas de la hoja `Tablas de Referencias`.
