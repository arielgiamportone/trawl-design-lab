# Bibliography

The references of this book reconstruct the sources cited by the original Excel model
(`legacy/Calculos_Red_FAO_A3.xlsx`). The sheet almost always names only the author of the method,
sometimes with a year (for example “Koyama 1974” or “Nomura”). For each one, the real work was
searched for in library catalogues (CiNii Books, university catalogues), in the FAO document
repository, in Crossref and in the reference lists of papers that apply those same formulas,
above all MacLennan (1981), Kim (1984), Mukundan and Shahul Hameed (1995), Vijayan and Baiju
(2006) and Okello (2014). No data were invented. Each entry of `referencias.bib` states in the
`note` field whether it is **verified** (with the URL of the source consulted) or remains **TO BE
VERIFIED**, and in that case explains what is missing. Some verified references rely on secondary
citations, that is, on the reference list of another work, and their note says so.
